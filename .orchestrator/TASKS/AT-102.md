## Frozen contracts

- `OrganizationState` and `RuntimeState` reducers are disjoint.
- Catalog uniqueness uses adapter/profile/native ID.
- IPC clients never access SQLite directly.
- Attachment version `(host_instance_id, generation)` makes stale detach/rebind events harmless across host restarts.
- Last-known runtime data is not presented as current liveness after restart.
- Tray-controller close and explicit Quit are different intents; this task does not modify the current GUI close path.
- IPC frames and subscriber queues use the frozen maximums; reconnect after continuity loss performs a new handshake and full snapshot.
- `/new` uses the frozen one-candidate `PendingIdentity` state and rebinds only after confirmation on `(host_instance_id, pane_id, native_session_id)`; a late end event for the old native ID cannot detach the new binding.
- Agent events arrive through ADR-002's reserved `Alert::SetUserVar`; no parser or GUI bridge is invented here.
- Agent launches opt into AT-107's `OwnedJob`; stock/direct launches do not.
- Runtime freshness is evidence-derived: owned process/pane evidence and typed exits control live state, and a new `HostInstanceId` invalidates old attachments immediately. Do not add the rejected universal 120-second runtime timer. Usage freshness remains a separate five-minute stale-on-open policy.

## Requirements

1. Schema/migrations for profiles, conversations, aliases, organization state, runtime attachments, usage snapshots, and reconciliation metadata.
2. Transactional upsert/dedupe and snapshot-versioned keyset pagination on `(last_activity_at, conversation_id)`.
3. Runtime attachment register/detach/rebind with generation checks.
4. A mux subscriber whose callback only validates/enqueues into the frozen bounded queue; decoder/reducer/SQLite work runs off the GUI thread and overflow produces deterministic `event_resync_required` reconciliation.
5. Pure settle/unsettle and stop command paths with negative invariant tests.
6. Startup reconciliation invalidating every prior-host attachment, plus typed AT-106 natural/killed exit handling, missing history, duplicate bindings, and catalog quarantine/rebuild.
7. Same-user named-pipe server with frozen bounded framing, `PIPE_REJECT_REMOTE_CLIENTS`, explicit owner-SID DACL, connected-client PID/token SID verification, bounded subscriber queues/drop-to-snapshot behavior, version negotiation, reconnect, and direct security tests.
8. Host commands for status/list/new/open/settle/unsettle/stop/refresh usage.
9. Tray-controller state machine for UI-close, reopen, explicit Quit, and stop-all intent through the frozen `CloseIntent`/Job boundaries without touching GUI/window code; AT-108 later binds it.
10. Synthetic 10,000-row query fixture, first-page deserialization bound, and raw timings.
