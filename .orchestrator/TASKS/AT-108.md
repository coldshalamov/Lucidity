## Objective

Bind the accepted host controller and `CloseIntent` foundation to a native Windows tray icon, deterministic reopen/focus, and explicit Quit that terminates only Agent-owned Job Objects.

## Exclusive write lease

- predeclared `agent-terminal/src/windows/**` tray/binding files
- exactly one smallest GUI/frontend hook path released by AT-101 and AT-105; the controller must name that concrete path in the external delegation ledger and launch receipt before dispatch
- no shared manifests or geometry/render paths

## Requirements

1. Tray HWND/message-loop ownership is explicit and single-instance. Exactly one message-only HWND is permitted for tray notifications; it is not a visible or hidden top-level application window.
2. Open restores/focuses the deliberately hidden existing mux window; it does not create a duplicate pane/window.
3. Window close selects `HideToTray`; tray Exit selects `QuitOwned`; settle selects neither.
4. Quit terminates all and only Agent-owned jobs, drains persistence, removes the tray icon, and exits once.
5. Explorer/taskbar restart restores the tray icon without changing runtime ownership.
6. Stock mode and stock application identity remain untouched.

## Acceptance

Controller-reproduced native Gate 2 close/debounce/reopen/PID/output receipts, tray identity, Explorer restart, duplicate-click/reentrancy, explicit Quit, and zero foreign-process impact.

## Stop and escalate

Any geometry change, any second hidden/visible top-level host window, an unnamed GUI path sublease, foreign-process enumeration/termination, or inability to distinguish true hide from minimize.
