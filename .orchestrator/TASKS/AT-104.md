## Objective

Translate the accepted native design into implementable tokens/state fixtures and build a thin VS Code/Cursor extension skeleton against a deterministic fixture host, with no dependency on unfinished Rust host or renderer work.

## Gate unlocked

Independent extension/demo path and visual implementation contract.

## Allowed paths

- `extensions/vscode/**`
- `docs/design/**`
- extension-specific fixtures under the accepted directory

## Forbidden paths

- Rust sources and manifests
- root Cargo/lock/config files
- `.orchestrator/**`, `HACKATHON/**`
- custom WebViews, xterm terminal attachment, provider/session-file access, or duplicate persistence

## Frozen contracts

- `.orchestrator/DESIGN/NATIVE_UI_CONTRACT.md` tokens, states, focus/keyboard behavior, and accessibility limits; this in-repository contract overrides conflicting external design prose.
- Versioned host protocol views/events from `agent-protocol` fixtures.
- Extension is a client only; desktop host owns lifecycle, data, and runtime truth.

## Requirements

1. Activity Bar container and Tree View sections: Current Workspace, Other Projects, Settled.
2. Agent/runtime icons, color-independent status, accessible labels, stable ordering, and context actions.
3. Commands: New in Current Workspace, Open/Focus, Settle, Unsettle, Stop, Refresh Usage, Open Lucidity.
4. Fixture-host client with version handshake, incremental events, reconnect, offline/error states, and deterministic tests.
5. Status-bar usage summary keeping quota/context semantics distinct.
6. Native VS Code APIs only; no WebView.
7. Design trace mapping each component/state to accepted tokens and screenshot fixture sizes.
8. Package/compile/test path that does not require the real desktop host.

## Acceptance tests

Compile, lint, and run extension tests; verify lazy activation, reconnect, incremental updates, exact workspace payload, every command, missing-host guidance, keyboard navigation, screen-reader labels, and fixed-size snapshots where the harness supports them.

## Stop and escalate

Cursor harness cannot be verified, protocol/design must change, a WebView seems required, a second state store appears, Rust source is needed, or platform evidence is unavailable.

## Completion packet

Return status; model/harness actually used; commit SHA(s); files; compile/test outcomes; fixture protocol version; accessibility/snapshot receipts; contract changes (`none` or proposal); risks; unresolved host integration; reviewer focus.
