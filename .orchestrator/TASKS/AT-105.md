## Requirements

1. A product-agnostic typed GUI close policy equivalent to `WindowClosePolicy::{Stock, HidePreservingMux}`. Per ADR-004, this package must not depend on `agent-protocol`; AT-108 later maps Lucidity's internal `CloseIntent` onto this seam.
2. A real Windows hide operation rather than `SW_MINIMIZE`.
3. A separate product-agnostic native minimize hook so the caption minimize button remains minimize after `hide()` becomes true hide; do not encode minimize as a Lucidity close-policy variant.
4. Reconciliation suppression that cannot respawn a deliberately hidden window.
5. Reopen/focus of the same mux window and pane identity.
6. The generic hide-preserving policy prevents `MuxNotification::Empty` from terminating its owning GUI loop and prevents a live pane from being pruned by default exit behavior. This task proves the product-agnostic policy; AT-108 supplies Lucidity intent mapping.
7. Stock mode retains current close/kill/minimize semantics exactly.
8. Typed show/focus and explicit-close hooks exist for later AT-108 tray reopen/Quit binding, but no tray icon or process termination is implemented here.

## Acceptance

- In an explicitly test-only generic GUI-policy native probe rooted in the leased sources, close/hide and observe no visible/taskbar window and `IsIconic == false` through the debounce interval while the exact mux pane/PID/output continues. The probe must not depend on `agent-terminal`, add a product mapping, edit a manifest, or be presented as the Gate 2 Lucidity tray receipt.
- Invoke the explicit minimize hook and prove the window is minimized/`IsIconic == true`, remains discoverable through normal Windows window-management surfaces, and preserves the exact mux pane/PID/output.
- Fire reconciliation/workspace notifications and prove no respawn.
- Show/focus the same native/mux window through the typed hook.
- Rerun stock close behavior and baseline smoke unchanged.

Product Agent-mode close-to-tray and tray evidence remain AT-108 acceptance. If the generic native probe cannot be built from the existing binary/unit-test surface without a non-leased entrypoint, stop and return the exact minimal test-seam proposal rather than widening the lease.
