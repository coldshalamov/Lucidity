## Frozen contracts

- Manifest, events, domain IDs, and IPC view types come from accepted `agent-protocol` and may not change.
- Direct executable-plus-args construction; no shell interpolation by default.
- `/new` changes native identity in the same process and PTY.
- Events use OSC 1337 `SetUserVar=lucidity.agent-event.v1=<base64 JSON>` and are bounded to 32,768 decoded bytes, versioned, idempotent, and non-panicking.
- Reducer fixtures carry the emitting host instance and pane context; a stale end event for the pre-`/new` native ID never detaches the new binding.
- The mock session store is deterministic and contains no secrets or machine-dependent timestamps unless a test supplies them.

## Requirements

1. TOML manifest parser and schema/semantic validation.
2. Executable discovery and version probe abstraction.
3. Windows-safe template expansion with hostile-argument tests.
4. ADR-002 event encoder/decoder for the frozen envelope, including exact reserved-name and maximum-boundary fixtures.
5. Reducer fixtures with `PendingIdentity`, duplicate/out-of-order/stale/unknown-version handling, evidence-ID cross-source dedupe, host-instance generation collision coverage, hint/crash/supersession/expiry, and old-ID-end-after-rebind coverage.
6. Mock harness commands: `/new`, `/work`, `/ask`, `/approve`, `/fail`, `/complete`, `/usage`, `/quit`; `/usage` emits the same structured `usage_updated` event used by the demo and never requires hidden host input.
7. `--resume <native-id>`, deterministic fake session store, and optional child process.
8. PTY-friendly terminal output and structured events with a monotonic sequence.
9. Fixtures for malformed, oversized, invalid UTF-8, reordered, duplicate, missing-field, and future-version events.
10. A test proving two durable identities from one process/pane after `/new` at the adapter/reducer level.

## Acceptance tests

Format/check/test `agent-backends`; run manifest/schema negatives; run the mock command transcript twice and compare normalized output/store hashes; prove process count stays one across `/new`; prove child cleanup hooks expose deterministic IDs. No network or live vendor credentials.

## Stop and escalate
