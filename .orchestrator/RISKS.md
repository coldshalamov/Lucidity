# Risk Register

| Rank | Risk | Trigger/evidence | Mitigation / fallback | Owner |
|---:|---|---|---|---|
| 1 | Terminal content or input escapes the reserved viewport | Current backends lack one obvious shared scissor primitive; padding/mouse clamps can map chrome clicks to cell 0 | One `AppLayout`; pure boundary tests; bounded quads plus both-backend proof; add real clip coherently if content escapes | AT-101 + Fable reviewer |
| 2 | Library/product binary extraction regresses stock behavior or silently loses Windows resources | Package is binary-only; build script owns manifest, DPI, icon `0x101`, version data, ConPTY/ANGLE/Mesa provisioning, while AppUserModelID is hardcoded | AT-099 builds the independent product-resource stub; AT-101 creates the real GUI library then adds the serialized path dependency; stock parity first; inspect PE/process DPI/icon/DLL/application identity before chrome evidence | AT-099/101/integration owner |
| 3 | Close-to-tray kills panes or a deliberately closed UI immediately respawns | `close_requested` kills the mux; hide means minimize; `forget_known_window` triggers reconciliation of still-live mux windows | Frozen `CloseIntent`; exclusive AT-105 lifecycle lease; true hide; reconciliation suppression; debounce window-count and exact PID receipts | AT-105 + integration owner |
| 4 | Folder/crate speculation creates needless upstream churn | Plans assume wrapper `upstream/wezterm`, but checkout has 67 existing packages and root-sibling convention | Preserve accepted root topology and three product packages; split only through ADR | Conductor/Fable/Kimi |
| 5 | Shared Cargo files collide across workers or an ignored binary-only path dependency enters the baseline | New packages need workspace/dependency/lock changes; Cargo warns and ignores a dependency on `wezterm-gui` before it has a lib target | ADR-004; AT-099 owns root/lock and the one `pty` feature declaration; AT-101 later owns only the mechanical `agent-terminal` GUI path-dependency/lock delta after creating the real lib | Integration owner |
| 6 | Runtime and organization state recouple through convenience APIs | Early plan proposed settle-and-stop; user explicitly rejected it | Separate commands/reducers/types; negative tests in every host/catalog review | AT-102/reviewer |
| 7 | `/new` creates false or duplicate identities | Raw input hint, multiple hints, crash/expiry, duplicate/out-of-order cross-source evidence | One `PendingIdentity`, 30s injected-clock expiry, stable evidence IDs, confirmation hierarchy, deterministic supersession/crash/reorder tests | AT-103/102 |
| 8 | Tray/process ownership leaks child trees | Stock PTY kills only the direct process; Job assignment/nesting/breakaway behavior unproven; `portable-pty` did not enable WinAPI `jobapi2` | ADR-003; AT-099 pre-enables only the pinned feature; atomic suspended-create/assign/resume; kill-on-close job; parent/child/grandchild and hard-crash receipts | AT-099/107/102/108 |
| 9 | Native UI looks polished but lacks form/accessibility behavior | WezTerm box model is not a mature app widget toolkit and exposes no Windows UIA/IAccessible provider | ADR-001 keeps keyboard/focus/contrast/semantics mandatory and forbids false screen-reader claims; two Opus passes; dedicated post-demo UIA gate | Design owner/AT-101 |
| 10 | Idle CPU/network regressions undermine the product thesis | Status/usage/history implementations drift into polling | Event-driven contracts; instrumentation; stock-relative release measurements | All reviewers |
| 11 | Kimi provider diversity is mistaken for review independence | Same model family through several providers | Kimi may parallelize disjoint work but never reviews Kimi; use verified Fable, Opus, or Sol cross-family review routes | Conductor |
| 12 | License contamination | Warp app is AGPL; T3/CCManager reuse needs exact provenance | Source ledger with commits/paths/classification; no copied code before license review | Integration owner |
| 13 | UAC/install side effects interfere with the run | Machine-wide Strawberry install blocked at consent UI | Use verified portable toolchain; no further machine-wide install; user may decline stale prompt | Controller |
| 14 | Scope outgrows hackathon corridor | Seven adapters/settings/mobile compete with identity/tray seam | Protected demo corridor and explicit cut line; native fallback controller window | Conductor |
| 15 | Host restart reuses attachment counters or stale old-ID events detach a new binding | Bare pane IDs and generation counters are process-local; event envelope has no trusted generation | `(host_instance_id, generation)` versions; pane/native-ID match; crash/restart and stale-end-after-rebind tests | AT-102/103 |
| 16 | Local IPC leaks cross-user data or an event subscriber exhausts memory | Default named-pipe DACL, remote clients, token mismatch, unbounded frames/queues, or reconnect assumptions | Owner-SID DACL, `PIPE_REJECT_REMOTE_CLIENTS`, connected-client PID/token SID check, fixed frame/queue bounds, resync/full snapshot semantics | AT-102/reviewer |
| 17 | Structured agent events never reach host or payload delimiters corrupt them | OSC 777 is dropped unless `notify`; raw semicolons split fields | ADR-002 reserved OSC 1337 SetUserVar path, base64 JSON, 32KiB bound, real ConPTY parser→mux→host receipt | AT-103/102 |
| 18 | Natural failure is mislabeled as completion | `PaneRemoved` carries no status and LocalPane currently discards observed exit details | AT-106 typed exit-before-removal notification; exact clean/nonzero/killed ordering tests | AT-106/102 |
| 19 | Pagination shifts or catalog corruption silently loses organization data | Offset pages mutate under concurrent activity; automatic rebuild could overwrite the only database | Snapshot-versioned keyset cursors; unique never-overwritten quarantine backup; visible recovery warning | AT-102 |
| 20 | Agent mode performs unsolicited upstream update networking | WezTerm update check defaults on and starts from first window | Hard-disable in Agent bootstrap; idle all-network receipt; stock mode unchanged | AT-099/101 |
